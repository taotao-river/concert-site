# 数据库搭建说明（技术小白版）

这个文件夹里有三个文件，用来在 Supabase 上建好网站的数据库。

## 文件说明

| 文件 | 作用 |
|---|---|
| `schema.sql` | 建表结构、索引、权限（先运行） |
| `seed.sql` | 预置首批 6 个艺人 + 示例数据（后运行） |
| `README.md` | 本说明 |

## 5 分钟搭好

1. 打开 https://supabase.com ，用邮箱/GitHub 注册（免费）
2. 点「New Project」，随便起个名字，设置一个数据库密码，地区选新加坡（离你近、大陆访问也相对快）
3. 等 1-2 分钟项目初始化完成
4. 左侧菜单点「SQL Editor」→「New query」
5. 打开本文件夹的 `schema.sql`，**全选复制**，粘贴到 SQL 编辑器，点「Run」
6. 同样方式，把 `seed.sql` 的内容粘贴运行
7. 左侧点「Table Editor」，就能看到建好的表：artists、venues、tours、events、sources、event_sources、articles

## 验证是否成功

在 SQL Editor 里运行：

```sql
select * from artists;
```

如果能看到泰勒·斯威夫特、阿黛尔等 6 个名字，说明成功了。

## 表是干嘛的（一句话版）

- `artists` 艺人：名字、类型、国家、社媒链接
- `venues` 场馆：名称、城市、经纬度（画地图用）
- `tours` 巡演：某个艺人的一轮巡演
- `events` 演出场次：**核心表**，存每场的时间、城市、票价、官方购票链接
- `sources` 数据来源：信息从哪来、什么时候抓的
- `event_sources` 关联：一场演出对应哪些来源
- `articles` 攻略文章：抢票攻略、城市指南（免费/订阅版）

## 重要提醒

- `seed.sql` 里的场次日期和场馆是**示例占位数据**，上线前必须核实替换
- 6 个艺人的基本信息是准确的，可以直接用
- 现在表是空的（除了示例），下一步是把真实巡演数据录进去
