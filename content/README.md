# content/ · 内容稿件

**这是第 0 阶段的主战场。**按 `CLAUDE.md` 第 1 节，现阶段精力分配是 内容 80% / 私域 15% / 网站 5%。

## 命名约定

```
艺人-主题.md          例：the-weeknd-亚洲场次汇总.md
平台-主题.md          例：ticketmaster-注册全流程.md
城市-行程.md          例：singapore-观演行程模板.md
```

艺人用 slug（与 `database/seed.sql` 的 `artists.slug` 一致），主题用中文。

## 每篇稿件的头部必须写清

```markdown
---
类型: 巡演场次 / 抢票攻略 / 行程指南
艺人: the-weeknd
平台: 小红书
状态: 草稿 / 已发布
数据来源: https://...（官网或官方公告链接）
核实时间: 2026-09-08
---
```

**没有来源和核实时间的稿件不发布。**信息错一次，付费用户就没了（`CLAUDE.md` 第 4 节）。

## 前 4 周只发这三类

按验证价值排序，其余选题先放着：

1. **「XX 巡演中文全场次 + 抢票时间线」** —— H1 主力，信息差最直接，最容易被收藏
2. **「Ticketmaster 注册全流程 / 内地卡能不能用」** —— 痛点最尖锐，最容易引来私信
3. **「去 XX 看演唱会全程花费拆解」** —— 引出行程需求，是 1v1 咨询的自然入口

完整 30 个选题库见《香港身份运营方案》9.2 节，使用顺序见 9.4 节。
