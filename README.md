# 全球演唱会地图（欧美明星抢票攻略站）

面向中国（华人）粉丝的欧美明星全球巡演信息与抢票服务。核心定位：**让每一个对欧美歌手有好感的人，都不再错过 TA 的演唱会。**

不卖票、不代订、不碰黄牛。

## 当前阶段：第 0 阶段 · 需求验证期

**现在不写产品代码。**这一阶段只做两件事：发内容、卖 1v1 咨询。

| 门禁 | 判据 | 状态 |
|---|---|---|
| H1 需求存在 | 小红书单篇收藏 >500 或累计私信 >20 | ⬜ 未开始 |
| **H2 有支付意愿** | **4 周内 1v1 咨询成交 ≥ 5 单** | ⬜ 未开始 |
| H3 联盟能转化 | 出现 ≥ 1 笔真实佣金入账 | ⬜ 未开始 |

**H2 是唯一的生死线。**它不过，后面所有模型都不用算。
完整方案见 [MasterPlan 第 12 节](项目总框架_MasterPlan.md)，规则见 [CLAUDE.md](CLAUDE.md)。

## 技术栈（第 1 阶段之后才用）

- 前端：Next.js + Leaflet/Mapbox（地图）
- 数据库：Supabase（PostgreSQL）
- 部署：Vercel + Supabase
- **数据源：艺人官网/官方公告 + 人工录入（首年主链路）**；Ticketmaster Discovery API 仅做校验
  - ⚠️ 「数据源全部免费」是错误假设。Songkick 新 key 基本不发放，Spotify 部分端点已停用，
    Ticketmaster 商用授权待确认。详见 [CLAUDE.md 第 5 节](CLAUDE.md)
